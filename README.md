# 지리 뉴스 브리핑 아카이브

매일 아침 텔레그램으로 발송되는 지리 브리핑의 **깊이 읽기(long-form)** 판입니다.
짧은 요약에서 잘려나간 방법론·수치·배경을 원문에서 다시 살려, 2022 개정 교육과정 성취기준과 연결해 분야별로 정리합니다.

**사이트:** https://xodn0109-glitch.github.io/geography-briefing/

## 구조

- `data/YYYY-MM-DD.json` — 하루 한 파일. 기사별 분야·본문·연구진·저널·이야깃거리(💬)·교육과정 연계(🎓)·태그와 원문의 URL·ISO 날짜·언어·DOI·정본 종류를 저장합니다.
- `build.py` — `data/*.json`을 모두 읽어 자기완결형 `index.html` 한 장을 생성. 표준 라이브러리만 사용.
- `index.html` — 생성물. 분야별 그룹(분야 안에서 최신순)·분야 필터 칩·본문 미리보기와 펼쳐보기·교육과정 연계 배지·다크모드.

## 갱신

운영의 유일한 실행 계약은 상위 폴더의
`.agents/skills/daily-geography-briefing/SKILL.md`입니다. 이 문서의 명령만 떼어
수동 발행하지 않습니다. 텔레그램 HTML·아카이브·사이트 JSON·검색 감사 기록이 같은
판본으로 검증되고, 텔레그램 대상 중 한 곳 이상에서 발송이 확인된 뒤에만
`SKILL.md`의 최종화 명령과 사이트 발행 명령을 적힌 인자까지 그대로 순서대로
실행합니다. 이 README의 축약 예시를 실행 계약으로 사용하지 않습니다.

첫 명령이 발송 판본을 고정하고 비공개 발행 영수증을 만든 뒤, `publish.sh`가 그
영수증과 교육과정·제목 게이트를 확인해 빌드, 커밋, 푸시를 순서대로 수행합니다. 직접
`git add`·`git commit`·`git push`로 이 게이트를 우회하지 않습니다. 발행 스크립트도
문서화된 사이트 소스·생성물·엄격한 날짜형 데이터만 stage하며, 그 밖의 경로가 이미
stage돼 있거나 untracked 상태이면 중단합니다. 과거 날짜 데이터의 삭제도 허용하지
않습니다. 새로 커밋할 변경이 없어도 푸시는 실행하므로, 이전 실행에서 로컬에만 남은
커밋도 다음 실행에서 원격으로 복구됩니다. 이때 추적 upstream 이후의 각 커밋을 따로
검사하고, 검증된 원격의 현재 브랜치 하나만 명시적으로 전송합니다.
발행 가능한 `origin`은 fetch URL과 push URL이 각각 정확히 하나이며 모두
`xodn0109-glitch/geography-briefing` 정본 GitHub 저장소를 가리켜야 합니다. 여러
`pushurl`, 다른 소유자·저장소, 로컬 경로 원격은 사전점검과 push 직전 검사에서
차단됩니다. 실행 날짜보다 미래인 `data/YYYY-MM-DD.json` 변경은 함께 발행하지
않습니다. 당일 또는 과거 회차에서 남은 변경은 각 날짜의 현재 정책 발행 영수증을
다시 검증한 경우에만 함께 stage해 미완료 발행을 복구합니다.

지도 윤곽 원본 `world_land_path.txt`는 검증 정책 지문에 포함되며, 빌더가 SVG path
명령·숫자·안전한 구분자 이외의 문자를 거부합니다. 이 파일을 직접 바꾼 뒤 검사를
우회해 발행하지 않습니다.

GitHub Pages가 push를 감지해 자동 재배포합니다.
